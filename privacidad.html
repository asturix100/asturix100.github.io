Política de privacidad

ORBIXTREME publicador · Última actualización: 17 de noviembre de 2026

Qué es

«ORBIXTREME publicador» es una herramienta de uso interno del canal de YouTube ORBIXTREME. Solo se conecta a la cuenta de YouTube del propio canal y no está destinada a otros usuarios.

Qué datos usa

Con el permiso del titular del canal, la herramienta accede a través de las API de YouTube a:

  • los datos de los vídeos del canal (títulos, descripciones, etiquetas, subtítulos, traducciones, listas de reproducción y programación), para gestionarlos;
  • las estadísticas del canal en YouTube Analytics (vistas, retención, países y otras métricas agregadas), solo para leerlas.

No accede a datos de otras cuentas ni recoge datos personales de los espectadores.

Cómo se guardan

El permiso de acceso se guarda únicamente en el ordenador del titular del canal. Los datos no se venden, no se comparten con terceros y no se usan para publicidad.

Uso de los datos de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado. La herramienta también está sujeta a las Condiciones del servicio de YouTube y a la Política de privacidad de Google.

Cómo retirar el permiso

El permiso puede retirarse en cualquier momento desde la cuenta de Google: myaccount.google.com/permissions.

Contacto

Para cualquier consulta, a través del canal de YouTube ORBIXTREME.
